# Online Chess

Шахматы в браузере: игра против компьютера (как раньше) и **игра против живого человека** по коду из 4 цифр.

- Правила и движок остались прежними — сервер проверяет каждый ход тем же кодом, который лежит в `public/index.html` (блок `engine-src`).
- Один файл сервера `server.js`, **без зависимостей** (нужен только Node 18+).
- Живые обновления через Server-Sent Events — на Render работает без настроек.

## Как играть

1. Нажми **Play online**.
2. Один игрок выбирает цвет и жмёт **Create game** — появится код из 4 цифр (и кнопка *Copy link*).
3. Второй вводит код и жмёт **Join** (или открывает ссылку вида `https://твой-сайт/?room=1234`).
4. После перезагрузки страницы игра в этой вкладке продолжается автоматически.

Онлайн отключены Undo и Hint. Скрытое меню «God mode» (4 быстрых клика по своему ферзю) работает и онлайн: после каждого чита вся партия отправляется на сервер, и соперник видит результат.

## Развернуть на Render

Вариант А (вручную):
1. Render → **New +** → **Web Service** → выбери репозиторий.
2. Runtime: **Node**, Build Command: `npm install`, Start Command: `npm start`, Instance Type: Free.
3. Deploy. Адрес вида `https://online-chess-xxxx.onrender.com`.

Вариант Б: **New +** → **Blueprint** → репозиторий; настройки возьмутся из `render.yaml`.

## Важно знать

- Комнаты хранятся в памяти сервера. На бесплатном тарифе Render сервис засыпает после ~15 минут без запросов и при перезапуске все партии теряются (клиент покажет «That game is no longer available»). Пока кто-то подключён, сервис не засыпает.
- Код из 4 цифр — это 10 000 вариантов; от перебора есть лимит попыток (15 в минуту на IP), но это не защита от целенаправленного подбора. Для приватных партий делись кодом только с соперником.
- Пустые комнаты удаляются через 30 минут (ожидание или конец партии) или через 3 часа (партия идёт, никого нет).
